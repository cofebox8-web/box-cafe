# بوكس كافي

نظام طلبات خدمة السيارات، بواجهة عربية RTL ومتجاوبة للهاتف والآيباد وسطح المكتب. الواجهة ملفات HTML وCSS وJavaScript ثابتة، بلا Node.js أو npm أو خطوة بناء. تستضيفها Vercel، وتستخدم Supabase للبيانات والمصادقة والتحديثات الحية.

## الصفحات

- `/menu/{branch}/{service-point-token}` — منيو الزبون والطلب عبر QR.
- `/roadside/order` — تسجيل طلب سريع بحساب موظف شارع مفعّل.
- `/kitchen/{branch}` — طابور تحضير طلبات الفرع.
- `/admin` — إدارة المنيو وسجل الطلبات.

## النشر

الموقع منشور على [box-cofe-web.vercel.app](https://box-cofe-web.vercel.app)، ومستودع GitHub الخاص هو `mustafambusiness-maker/box-cofe-web`. إعداد `vercel.json` يحدد أن المشروع ثابت، ويستخدم مجلد `public` كمجلد النشر، ويضبط مسارات الصفحات. النشر يتجدد تلقائياً مع تحديثات `main`. لا تضف أمر build أو install.

إعداد Supabase العام موجود في `public/js/config.js` ويستخدم مفتاح `publishable` فقط. لا تضع مفاتيح `service_role` أو أسراراً في ملفات المتصفح. تُحفظ تغييرات قاعدة البيانات بترحيلات مرتبة في `supabase/migrations/`.

## التشغيل والتهيئة

- اقرأ `docs/architecture.md` لمعرفة تدفقات النظام وحدود كل دور.
- اقرأ `docs/supabase-first-run.md` لتهيئة Supabase وحساب المالك.
- يبدأ المنيو بلا أصناف أو حسابات موظفين تجريبية؛ يضيفها الأدمن الرئيسي يدوياً.
- لا تستخدم مسارات الكاشير أو المصاريف التجريبية في المحاسبة التشغيلية.
